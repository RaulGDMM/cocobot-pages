¿Qué es scrcpy?

scrcpy es una herramienta de código abierto (de Genymobile/Google) que permite espejar la pantalla de tu dispositivo Android en tu Mac en tiempo real, con muy baja latencia. Además puedes:

  • Controlar el móvil desde el ratón y teclado del Mac
  • Grabar la sesión en vídeo (.mp4)
  • Tomar capturas de pantalla
  • Funcionar por USB o por WiFi (sin cables)
¿Por qué scrcpy y no QuickTime? QuickTime solo soporta capturas de pantalla de dispositivos iOS. Para Android, scrcpy es la alternativa estándar de la industria.

1 Instalar Homebrew

Homebrew es el gestor de paquetes de macOS. Necesitarás Homebrew para instalar ADB y scrcpy de forma sencilla.

¿Ya tienes Homebrew?

Ejecuta en Terminal:

brew --version

Si ves algo como Homebrew 4.x.x, ya lo tienes y puedes saltar al paso 2. Si dice command not found, sigue con la instalación.

Instalar Homebrew

Abre Terminal (lo encuentras en Aplicaciones → Utilidades → Terminal o buscando con Spotlight ⌘ + Espacio → escribe "Terminal") y ejecuta:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

El instalador te pedirá tu contraseña de Mac y te hará unas preguntas. Acepta todo. Al terminar, ejecuta:

brew --version
Verificación Si ves la versión de Homebrew, ya estás listo para el siguiente paso.

2 Instalar ADB (Android Debug Bridge)

ADB es la herramienta que permite comunicarse con el dispositivo Android desde el Mac. scrcpy lo necesita.

brew install --cask android-platform-tools

Verifica que se instaló correctamente:

adb --version
Advertencia de seguridad de macOS La primera vez que ejecutes adb, macOS puede mostrar: "Apple no ha podido verificar que adb no contenga software malicioso...". Esto es una advertencia estándar — ADB es software oficial de Google y es seguro. Haz clic en el mensaje, ve a Ajustes del Sistema → Privacidad y seguridad y pulsa "Abrir de todos modos".

3 Activar Depuración USB en Android

Antes de conectar el móvil, necesitas activar las opciones de desarrollador y la depuración USB:

  1. Ve a Ajustes → Acerca del teléfono
  2. Busca "Número de compilación" (Build number)
  3. Toca sobre él 7 veces rápidamente — aparecerá un mensaje: "Ya eres desarrollador"
  4. Vuelve atrás y entra en Opciones de desarrollador (ahora visible)
  5. Activa Depuración USB (USB debugging)
Nota Algunos dispositivos Samsung ocultan la depuración USB dentro de un submenú. Busca "Depuración USB" directamente en la barra de búsqueda de Ajustes.

4 Instalar scrcpy

brew install scrcpy

Verifica:

scrcpy --version

5 Conectar y usar

Conexión por USB (recomendada)

  1. Conecta el Android al Mac con un cable USB
  2. En la pantalla del móvil aparecerá un diálogo: "¿Permitir depuración USB desde este equipo?" — marca "Siempre permitir" y acepta
  3. En Terminal del Mac ejecuta:
scrcpy

¡Listo! Se abrirá una ventana con la pantalla del móvil en directo.

Conexión por WiFi (sin cables)

  1. Conecta primero por USB y ejecuta:
adb tcpip 5555
  1. Desconecta el cable USB
  2. Encuentra la IP del móvil: Ajustes → Wi-Fi → toca la red conectada
  3. Conecta por WiFi:
adb connect IP_DEL_MOVIL:5555

Por ejemplo: adb connect 192.168.1.42:5555

  1. Ejecuta scrcpy sin argumentos:
scrcpy

Funciones útiles

Grabar vídeo

scrcpy --record=grabacion.mp4

El vídeo se guarda en el directorio actual de Terminal. Para grabar en una carpeta específica:

scrcpy --record=~/Videos/grabacion.mp4

📸 Captura de pantalla con macOS (al portapapeles)

Esta es la forma más rápida de tomar capturas para incluirlas en tus ejecuciones de pruebas (Xray, etc.). La captura se guarda directamente en el portapapeles del Mac, lista para pegar con ⌘ Cmd + V.

  1. Con la ventana de scrcpy abierta y visible
  2. Pulsa ⌃ Ctrl + ⌘ Cmd + ⇧ Shift + 4
  3. El cursor se convertirá en una cámara de captura
  4. Pulsa Espacio — el cursor se convertirá en una cámara
  5. Mueve el cursor sobre la ventana de scrcpy (se resaltará) y haz clic

¡Listo! La captura está en el portapapeles. Pégala directamente con ⌘ Cmd + V en Xray, Slack, Google Docs, o donde necesites.

Ventaja sobre la captura nativa de scrcpy Con este método la imagen va al portapapeles, no a un archivo. Puedes pegarla inmediatamente sin tener que buscar el archivo, arrastrarlo, ni copiarlo manualmente. Ideal para documentar bugs y ejecuciones de QA.

Captura desde scrcpy (guarda archivo)

Alternativamente, scrcpy tiene su propio atajo que guarda un archivo .png en el directorio actual de Terminal:

⌘ Cmd + ⇧ Shift + S

Se guarda como scrcpy-screenshot-XXXX.png. Útil si necesitas el archivo para adjuntarlo después.

Resolución de problemas

❌ "ERROR: Command not found: [adb]"
ADB no está instalado o no está en tu PATH. Ejecuta brew install --cask android-platform-tools y vuelve a intentarlo. Si ya lo instalaste, cierra y reabre Terminal.
❌ "scrcpy: device not found"
Verifica: (1) Depuración USB activada en el móvil, (2) Diálogo de permiso aceptado en pantalla, (3) Cable USB funciona. Ejecuta adb devices — si no aparece el dispositivo, el problema es ADB, no scrcpy.
❌ "adb: command not found" después de instalar
Cierra Terminal completamente y ábrelo de nuevo. Homebrew añade rutas al PATH que solo se cargan al iniciar una nueva sesión. También puedes ejecutar source ~/.zshrc para recargar sin cerrar.
❌ El móvil no aparece en adb devices
Prueba en este orden: (1) Cambia el cable USB, (2) Prueba otro puerto USB del Mac, (3) Desactiva y reactiva Depuración USB, (4) Desbloquea la pantalla del móvil y vuelve a aceptar el diálogo de permiso, (5) Reinicia el servidor ADB con adb kill-server && adb start-server.
❌ macOS bloquea adb — "software malicioso"
Es una advertencia estándar de macOS. Ve a Ajustes del Sistema → Privacidad y seguridad → baja hasta ver el mensaje sobre adb → pulsa "Abrir de todos modos". ADB es software oficial de Google.
❌ La conexión WiFi no funciona
Asegúrate de que Mac y móvil están en la misma red WiFi. Verifica la IP del móvil (Ajustes → Wi-Fi → toca la red conectada). Si sigue fallando, prueba adb connect IP_DEL_MOVIL:5555 manualmente. Algunos routers aíslan dispositivos — desactiva "AP Isolation" o "Client Isolation" en el router.
❌ La imagen se ve pixelada o con baja calidad
Aumenta el bitrate: scrcpy --bit-rate=16M. También puedes forzar una resolución más alta: scrcpy --max-size=1920. Si usas WiFi, la calidad puede verse limitada por la velocidad de tu red.
❌ Samsung: no encuentro "Depuración USB"
En Samsung, dentro de Opciones de desarrollador, busca el submenú "E/S depuración" o "Debugging". La Depuración USB está dentro. También puedes buscar "Depuración USB" directamente en la barra de búsqueda de Ajustes.
❌ Tengo varios dispositivos conectados
Usa adb devices para ver la lista y sus IDs. Conecta a uno específico con: scrcpy -s ID_DEL_DISPOSITIVO

brew install --cask android-platform-tools  # ADB
brew install scrcpy                          # scrcpy

# Conectar por USB
scrcpy

# Grabar
scrcpy --record=~/Videos/test.mp4

# Captura al portapapeles (macOS)
# ⌃Ctrl + ⌘Cmd + ⇧Shift + 4 → Espacio → clic en ventana scrcpy
# Pegar con ⌘Cmd + V

adb tcpip 5555
adb connect 192.168.1.XX:5555
scrcpy
