03Instalación: de cero a ComfyUI

ComfyUI es el motor de todo el catálogo: un grafo de nodos al que se le puede hablar por API, ideal para personas y agentes. Los modelos se descargan a la carpeta de modelos según la ruta que indica cada ficha.

Windows (el camino fácil)

  1. Descarga el portable oficial de ComfyUI (nvidia) desde la web oficial y descomprime.
  2. Arranca run_nvidia_gpu.bat y abre http://localhost:8188.
  3. Instala ComfyUI-Manager (git clone en custom_nodes/) para añadir nodos faltantes con un clic.
  4. Verifica la API: curl http://localhost:8188/system_stats debe devolver dispositivos CUDA.

Linux (servidor)

  1. git clone https://github.com/comfyanonymous/ComfyUI + python -m venv venv + pip install -r requirements.txt (PyTorch CUDA según tu driver).
  2. Arranca python main.py --listen 0.0.0.0 y verifica GET :8188/system_stats.
  3. Modelos vía hf download <org/repo> --local-dir a la ruta que pide cada nodo.
  4. Si la GPU la usan varios agentes a la vez: pon una pasarela con cola única delante (patrón broker, referencia comfyui-broker.py en el repo).
Consejo para agentes: instala primero ComfyUI + Manager, y descarga cada modelo solo cuando el usuario elija esa capacidad — ahorras cientos de GB y horas de descarga.

05Lecciones de campo (cada una costó un fallo real)

QA perceptual a ojo, nunca métricas medias

Un diff medio de píxeles entre int8 y bf16 dio 1,2/255 («imperceptible») y el lado a lado demostró lo contrario. Los A/B de calidad se juzgan viendo las imágenes juntas.

En refine/upscale, la identidad vale más que la textura

Subir la curva σ del refiner compra detalle pero reescribe micro-atributos (nariz, iris, manos) y hasta la especie en planos con varios sujetos. Criterio: bajar σ antes que aceptar deriva de identidad; el ancla de croma (Y refinada + Cb/Cr del draft) arregla color, nunca forma. Revisa TODAS las caras visibles, no solo la principal.

El parche de memoria de atención cuantizada rompe clips largos

Cuantificar Q/K int8 + V fp8 en el refiner H3 pasó de «ahorra VRAM» a salida basura en clips >5 s sin dar error. Si algo sale uniforme y malo, sospecha de parches silenciosos antes que del modelo.

Ningún editor de imágenes es pixel-preserving

Si el prompt contradice a la foto, todos los modelos instalados inventan lo pedido y se cargan los píxeles. Describe el FRAME FINAL esperado, no el cambio.

Entrenadores de texto = filtros de seguridad dentro del peso

Un modelo nº1 de leaderboard bloqueó con falsos positivos prompts inocentes de etiquetas de precios; la solución fue pasarle captions JSON estructurados. Conoce el sesgo de entrada de cada modelo.

int8 no siempre es más rápido en GPU de ancho de banda alto

En la 5090, muestrear Qwen-Image en int8 y bf16 costó lo mismo (~18 s): el cuello es de ancho de banda, no de cómputo. El formato más pequeño ganó en carga, no en muestreo.

El agente y la GPU necesitan una cola

Dos agentes disparando a la misma GPU = OOM y carreras. Un broker con cola única que serializa trabajos (y pausa al agente mientras genera) hizo todo el stack fiable.

Un flag óptimo mal cableado falla en silencio

El A/B de un flag de mejora de prompt se midió sin que el nodo estuviera realmente en el grafo. Verifica que el nodo aparece en el workflow enviado, no solo en el script.
